# PotatoBrawl

1v1 platform fighter (browser, phone + desktop) with lockstep online play. Live at https://potatobrawl.cloud.
Read docs/WORKFLOW.md (how we work) and docs/HANDOFF.md (state, rules, next steps) before starting.

## Layout
- `game/` source. `core.js` deterministic simulation (exported as `BL`, also a node module); `ui/*.js` page logic (one script split into parts, joined in order by build.py; PROTO lives in `ui/online.js`);
  `ui/cup.js` the offline 8-player tournament (bracket screen, P.cup; UI only); `ui/acct.js` + `sync.js` profile pill, Account sheet and sync code (UI only; `sync.js` is the pure merge, also a node module); `ui/quick.js` + `css/96-quick.css` Quick match: search, CPU warm-up, VS, results (UI only; the server decides Ranked; on our server only); `ui/bossweek.js` + `css/97-bwrun.css` Boss Week: the week, the tickets, the run's clock pill and the results card (UI only; the server deals and checks every try); `ui/bwsheet.js` + `css/97-bossweek.css` its start tile, sheet, Boards tab and Monday card (UI only); `ui/replay.js` replays: a Boss Week run or Ranked vs CPU match played again from its logged inputs through the match screen, seek, the `#watch=<id>` share link (UI only, nothing it plays counts); `ui/rpview.js` + `css/97-replay.css` its controls strip, end card, title card and the WATCH buttons (UI only); `ui/vscpu.js` + `css/96-vscpu.css` Ranked vs CPU, the VS CPU choice on Quick match (UI only; the server deals and checks every match); `ui/boards.js` + `css/97-boards.css` the Boards sheet (CPU board, Online board); `ui/challenge.js` + `css/96-challenge.css` Challenge a friend after a 1v1: hosts a Play friends room and shares its link (UI only); `ui/hud.js` match HUD extras: the YOU/CPU marker fade, the danger edge glow and the see-through fight buttons (`css/91-pads.css`) (UI only, reads the sim, never writes it); `ui/welcome.js` + `css/99-first.css` first open: the turn-sideways screen and the welcome sheet (the 4-step tutorial and the first fight's hints are `ui/tutorial.js`; UI only); `ui/online-team.js` online Team Brawl 2v2 for up to four phones (the board, the four-phone lockstep with CPU seats run on every phone, drops, repair copy; styles in `css/96-board.css`); `ui/finisher.js` KO finisher cinematic (UI only, never touches the sim); `ui/skins.js` the Skins bar + Skin Rack sheet on the fighter select (UI only; the Play friends lobby is in `ui/online.js`, styles in `css/90-skins.css` / `css/95-lobby.css`); `ui/shop.js` + `css/93-shop.css` the Account sheet's Shop tab: nameplates, Glaze, the Daily's Another go (UI only; the Locker tab's styles are `css/92-locker.css`); `ui/harvest.js` + `css/94-harvest.css` the Harvest, 30 daily gifts on the Daily sheet behind the flame (UI only; `P.harvest`, merged in sync.js); `ui/glaze.js` the Glaze pearl sheen drawn over a glazed skin (UI only, a WeakSet mark, never in the sim; travels online in presence as `gz`); `ui/manga.js` + `manga/*.js` the 2D manga KO finisher pages, one per fighter, eight pages, each with its Ultimate cut (`S_.ulti`) and its Potatality (`S_.alt`, the food-gag page bought with Pommes) (UI only); `ui/kopages.js` which KO page plays (your Potatality if on, a friend's from presence `ko`, the CPU's teaser), this device's copy of the server's Pommes, and WATCH (UI only); `skinfx.js` skin effects; `shell.html` markup + CSS; `net-ws.js` WebSocket
  shim for the server build; `mock-room.js` two-tab test room; `portraits/`.
- `python3 game/build.py` writes `index.html` (repo root, the deployed file), `public/` (local server) and
  `build/` (test pages). Commit the rebuilt `index.html` together with the source change.
- `web/` manifest + icons for the home-screen app (copied into `public/` by build.py and the deploy blocks).
- `server.js` serves `public/` + WebSocket rooms; `accounts.js` the optional sync-code accounts (off unless `ACCOUNTS_DIR` is set); `quick.js` the Quick match queue and Ranked referee (replays the relayed inputs with core.js, keeps the online rank in the account files; Casual only without accounts); `cpurank.js` Ranked vs CPU and the boards (deals each ranked CPU match, replays the player's logged inputs with core.js, keeps the CPU rank in the account files' `cpu` part; off without accounts); `bossweek.js` Boss Week (one boss a week, deals each try, replays a new best with core.js, pays the week on Monday into the account files' `bw` part and keeps the week files in `<accounts>/weeks/`; `GET /api/run/<id>` gives a run to watch; off without accounts); `pommes.js` the Pommes wallet: the account files' `pm` part (only the server writes it), buying a Potatality, the ledger `<accounts>/pommes.log`, and the requests of `tools/pommes.js` (Jonny's support tool: show, grant / take back, move to a new code); off without accounts; chips are never sold for Pommes; `stats.js` the anonymous play counts and Jonny's private `/stats` page (`web/stats.html`; off unless `STATS_DIR` is set; the game side is `game/ui/counter.js`, UI only). `deploy/` holds the server paste blocks.
- `tests/` node + Playwright checks, `experiments/` prototypes not yet in the game.

## Rules
- core.js must stay deterministic (no Math.random / Math.sin in the sim). A change that can alter simulation
  results adds new fighter fields to defaults, FKEYS and checksum, and bumps `PROTO` in ui/online.js (deploy/update.txt needs no change: it compares the served page with GitHub's).
- No service worker. Anything that adds ports, stored data or dependencies on the VPS is Jonny's call
  (it also runs his trading bot).
- Present a plan to Jonny before changing game code.
