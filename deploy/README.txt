players.txt       read-only: players so far, players per day, play time, where first visits end, and the accounts, from the play counts' day files (curl ... | bash, see its first lines)

beta-update.txt   put any branch on the beta address to try it before it goes live
first-setup.txt   first-time install of Node, the potatobrawl user, the repo and the systemd unit

accounts-setup.txt  one-time: switches on accounts (sync codes). Paste it once as root, after update.txt has put the version with accounts.js live. It creates /var/lib/potatobrawl/accounts, tells the game about it (systemd drop-in, game listens on 127.0.0.1 only), installs a nightly backup (14 days in /var/backups/potatobrawl), restarts the game, prints "accounts are on" and "the site still works", and then closes port 8080 in the firewall. Until it is pasted the game works as before, the Account sheet says "Saving to an account isn't available yet." and Quick match is Casual only (Ranked needs the accounts: they hold the online rank).
stats-setup.txt   one-time: switches on the play counts (anonymous totals per day, no IDs, IPs or cookies) and prints the private link to the stats page (https://potatobrawl.cloud/stats#<key>). Paste it once as root, after update.txt has put the version with stats.js live. It creates /var/lib/potatobrawl/stats, tells the game about it (systemd drop-in), restarts the game and prints "play counts are on" with the link. Pasting it again prints the link again. Until it is pasted the game sends one request per visit, gets a 404 and stops.
